# AGENTS

This repository is a Video to Live Photo app.

The app takes a video input and converts it into an Apple Live Photo.

For implementation details and validation rules, see [Live Photo minimum requirements](LIVE_PHOTO_MINIMUM_REQUIREMENTS.md).
For a known-working downloaded sample that can be used as a metadata reference, see [Working downloaded Live Photo report](LIVE_PHOTO_REPORT_WORKING_DOWNLOADED.md).
For a known-working directly captured sample that can be used as a metadata reference, see [Working captured Live Photo report](LIVE_PHOTO_REPORT_WORKING_CAPTURED.md).
For the first failing sample produced by our app's latest build, see [Not working app build 1 Live Photo report](LIVE_PHOTO_REPORT_NOT_WORKING_APP_BUILD_1.md).
For product and technical ideas derived from WidgetClub's Live Photo flow, see [WidgetClub reference notes](LIVE_PHOTO_WIDGETCLUB_REFERENCE_NOTES.md).
